# AUREVIA Fashion Store

A premium multi-page fashion shopping experience built with React, Next.js and Vinext.

## Features
- 12 product catalogue with search, category filters and price sorting
- Product detail pages with size and colour selection
- Persistent wishlist and shopping bag
- Responsive cart and email-based checkout
- About and contact pages
- Mobile-friendly luxury editorial design

## Local setup
```bash
pnpm install
pnpm dev
```

Customer enquiries are delivered through FormSubmit to the store owner.
